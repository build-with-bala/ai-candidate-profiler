> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Paths.** `<A>` and `<B>` stand for the roots of the local checkouts of A (`build-with-bala/ai-candidate-profiler`) and B (`build-with-bala/ai-practice-report`). `<research>` stands for the private research notes, which are in neither repo. `<scratch>` stands for the session scratchpad, a folder outside both repos. The controller gives the concrete paths at dispatch.

**Goal:** Create the public repo `build-with-bala/ai-practice-report` and its `core/` engine up to `scan()`: streaming IO, a typed event model that carries no free text, in-memory text features, and correct readers for the five P0 tools (Claude Code, Codex, Copilot, Cursor, Antigravity), proven on synthetic fixtures and on real local data.

**Architecture:** One plugin per tool store locates it per OS, streams it, turns records into typed events (numbers, flags, enums, keyed hashes) and reports coverage plus format drift. `scan()` runs the plugins and returns an in-memory `EventStore`, coverage, warnings, and a private cwd map. Raw text never leaves a plugin.

**Tech Stack:** Bun 1.3.11, TypeScript 5 (`strict`), `bun:sqlite`, `node:crypto`, `bun test`. No runtime dependencies.

**Spec:** `<A>/docs/superpowers/specs/2026-11-17-ai-leverage-suite-v2-design.md` — this plan implements §3, §6.1–§6.3, the read classes of §6.1/§6.7, §9 (core layout), §10 (tests, CI) and §11 phases P0–P1.

## Global Constraints

- Bun ≥ 1.3 (CI pins `1.3.11`); TypeScript `strict: true`; ESM; no native addons; no runtime dependencies (devDependencies only: `typescript`, `@types/bun`).
- SQLite is opened only via `openRo()` (Task 5), i.e. `new Database(sqliteUri(path) + "?mode=ro", { readonly: true })`; never `immutable=1`; never `SELECT *`; parameterized queries with explicit column lists.
- Events carry no free text: only numbers, booleans, enums, epoch ms, built-in tool names, model ids, version strings, keyed hashes. Exception, documented and canary-exempt: `ConfigEv.name` and `ToolEv.mcpServer` hold raw config names for the Plan 2 allowlist and are never exported raw.
- Never opened: `auth.json`, `*.key`, Copilot `apps.json`/`hosts.json`, credential/account tables, OS keychains. Mixed files are parsed in memory and only allowlisted fields are kept. Never kept: `oauthAccount.emailAddress`, MCP `env` blocks, `pastedContents.content`, `oauthToken`, `ai-title` records, subagent meta `description`. SQL never selects Codex `first_user_message`, `title`, `preview`.
- Repo content is synthetic only: fixtures are generated by code under `test/`; each `FORMAT.md` documents record types, field names and value *types* — never values.
- Real local traces may be inspected **only** with `bun scripts/probe.ts` (Task 7, structure only). Never `cat`/`head`/`jq`/`sqlite3` real trace files; never paste a value from them into code, docs, commits, PR text or reports.
- Streaming everywhere: `MAX_LINE_BYTES = 33_554_432`; no whole-file caps; `readFileSync` only for JSON files ≤ 8 MiB via `readJsonSmall`.
- No temp files by default; fallback copies live under a 0700 dir from `TempRegistry` and are removed in `finally` and on SIGINT/SIGTERM.
- Core makes no network requests.
- Project identity = `keyedHash(salt, normalizePath(cwd))`; raw cwds exist only in `ScanResult.cwds` (memory).
- `ctx.log(level, code, n?)` takes enum-like codes only — never strings derived from trace content.
- Every commit message ends with the `Co-Authored-By:` trailer for the model that authored the commit, as that agent's own harness specifies (e.g. `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` for Sonnet 5.5, `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` for Opus 5.5). Before every push, run the EtherHiding config scan from the workspace `CLAUDE.md`; network commands (`git push`, `gh`) need `dangerouslyDisableSandbox: true`.
- Performance budget, enforced by Task 16: full scan of the real local history ≤ 60 s cold, peak RSS ≤ 1 GiB.

## Review Focus

1. A multi-hundred-MB transcript with a truncated last line or a 7 MB single line → the scan finishes, `skipped` counts it, memory stays bounded. Pinned by Task 4 tests.
2. A store locked by the running app (SQLite busy) → falls back to a private copy that is deleted afterwards; no temp leftovers. Pinned by Task 5 tests and Task 16's `tempClean` assertion.
3. A newer CLI writes record types or fields the reader doesn't know → coverage status `drift` with `unknownTypes` counts; known records still parsed; never a silent zero. Pinned by Tasks 9, 11, 13 tests.
4. Paths with spaces, unicode, or backslashes (`Application Support`, `Antigravity IDE`, `C:\Users\Jo Ann\…`) → locate finds them and SQLite URIs open them. Pinned by Task 2 and Task 5 tests.
5. Timestamps as seconds, ms, numeric strings or ISO strings, missing timestamps, and local-day boundaries under `TZ=Pacific/Auckland` → correct epoch ms and day keys; no 1970 dates. Pinned by Task 4 `toEpochMs`/`localDay` tests and Task 10's daily test.

```ts
export const MAX_LINE_BYTES = 33_554_432;
export type JsonlItem = { n: number; value: unknown } | { n: number; skip: "oversize" | "parse" | "sniffed"; bytes: number };
export interface JsonlOpts { sniffSkip?: (head: string) => boolean; headBytes?: number /* 512 */; maxLineBytes?: number; signal?: AbortSignal }
export function readJsonl(path: string, opts?: JsonlOpts): AsyncGenerator<JsonlItem>;
export function toEpochMs(v: unknown, now?: number): number | undefined;   // accepts s, ms, numeric strings, ISO; rejects < 2015-01-01 and > now + 2 days
export function localDay(ms: number, timeZone?: string): string;            // "YYYY-MM-DD" via Intl.DateTimeFormat (en-CA)
export function safeList(dir: string): string[];
export function safeStat(p: string): import("node:fs").Stats | null;        // lstat; null on error
export function readJsonSmall(p: string, maxBytes?: number /* 8 MiB */): unknown | undefined;
export function walk(dir: string, opts: { maxDepth: number; match: (name: string, isDir: boolean) => boolean }): string[]; // never follows symlinks
```
- Algorithm (`readJsonl`): iterate `Bun.file(path).stream()` chunks as bytes; split on `0x0A` with a carry buffer; once the carry for the current line exceeds `maxLineBytes`, discard bytes until the next newline and yield `{ skip: "oversize" }`; decode only the first `headBytes` of each line for `sniffSkip` and yield `{ skip: "sniffed" }` without decoding the rest; otherwise decode, strip a trailing `\r`, skip blank lines silently, `JSON.parse` (failure → `{ skip: "parse" }`); a final line without `\n` is still parsed; `n` is the 1-based line number.
